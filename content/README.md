# பூஜாநிதி — உள்ளடக்கம் சேர்ப்பது / திருத்துவது

இந்த `content` கோப்புறையில் உள்ள `.txt` கோப்புகளைத் திருத்தினால் போதும். GitHub-ல் "Commit changes" அழுத்தியவுடன் ஒரு நிமிடத்தில் ஆப் தானாகப் புதுப்பிக்கப்படும். கணினி code எதுவும் தெரிய வேண்டியதில்லை.

- `puja/` — ஒவ்வொரு பூஜைக்கும் ஒரு கோப்பு (உதா: `vinayaka-chaturthi.txt`)
- `puja/_common/` — எல்லா பூஜைகளிலும் வரும் பொதுப் பகுதிகள் (விக்நேஶ்வர பூஜை, கலஶ பூஜை, ப்ராணப்ரதிஷ்டை…). இங்கே திருத்தினால் எல்லா பூஜைகளிலும் திருந்தும்.
- `katha/` — வ்ரத கதைகள்
